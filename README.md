# Candidate Presence Tracker

Je veux gerer les presences de ces candidats, tu dois permettre la selection d'un candidat a chaque date depuis le 21 au 25 septembre 2026. Une presence est unique pour une journee. Ca doit finir par creer un tableau de bord des presences, un fichier pdf des presences fois 5000BIF de frais de deplacement
